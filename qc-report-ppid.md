**Inti masalah:** (1) data uji/dummy dan salah-desa ("Desa Punggul") tampil di halaman resmi PPID; (2) API publik membocorkan nama responden survei serta email/telepon/alamat pegawai (termasuk yang nonaktif); (3) bagan Struktur PPID tidak terbaca di HP/tablet; (4) link footer "Informasi Publik" dan "Transparansi" mati (404) di semua halaman; (5) halaman detail dengan ID tidak valid hanya menampilkan skeleton/kosong tanpa pesan.

**Yang lolos:**
- Semua 8 submenu PPID memuat **HTTP 200** di 3 ukuran layar; tidak ada scroll horizontal halaman (scrollWidth = clientWidth = 375/768/1440).
- Tidak ada teks `undefined` / `null` / `NaN` / `[object Object]` / `Invalid Date` / lorem ipsum (cek case-sensitive pada teks halaman).
- Tidak ada gambar rusak dan tidak ada `<img>` tanpa atribut `alt` pada konten PPID; tidak ada request 4xx/5xx saat memuat 8 halaman utama (selain sengaja pada uji 404 / ID invalid).
- Tidak ada console error di 8 halaman utama (hanya satu warning Recharts di IKM, lihat No. 28).
- Semua API data PPID menjawab 200 dalam waktu singkat; waktu muat halaman 1,2–2,5 detik (muat pertama dingin: Profil 4,7 dtk, Struktur 6,5 dtk di HP).
- URL tidak ada di bawah `/darmasaba/ppid/` mengembalikan **HTTP 404** asli (bukan soft-404).
- Format tanggal Indonesia benar ("28 Agustus 2026", "21 Februari 2025", "01 Januari 2020"); format angka ribuan tidak relevan di menu ini (angka kecil).
- Validasi inline form Permohonan Informasi berfungsi: NIK harus 16 digit ("NIK harus 16 digit"), format email ("Format email tidak valid"), NIK/telepon menolak huruf (otomatis disaring) dan dibatasi 16/13 digit; form Keberatan: "Nomor telepon minimal 10 digit" dan format email. Tombol Kirim mati sampai semua syarat terpenuhi.
- Pencarian Daftar Informasi Publik benar (hasil sesuai dan pesan "Tidak ada informasi publik yang ditemukan." untuk kata tanpa hasil); paginasi 5/halaman benar (total 3 → 1 halaman); sanitasi input `<b>x</b>`/`%` tidak membuat error.
- Navbar: submenu PPID desktop (hover) dan hamburger HP menampilkan 8 item benar, item aktif ditandai; HTTP→HTTPS redirect 301; fokus keyboard (Tab) memiliki outline 2px terlihat.
- Data IKM konsisten antar sumber: API (6 responden: Mei 2026 = 3, Juli 2026 = 3; 4 L / 2 P; Sangat Baik 3 / Baik 3; Muda 2 / Dewasa 4) = grafik di UI.
- Detail daftar informasi publik valid (data uji & non-uji) tampil benar dan sama dengan API; tombol "Kembali" berfungsi.

### Tidak bisa dites & alasannya

| Item | Alasan |
|---|---|
| **WebKit/Safari** | Playwright WebKit diketahui crash (Bus error) di mesin ini; sesuai instruksi tidak dicoba ulang dan Safari MCP tidak dipakai. Perlu dites manual di Safari (terutama kartu bagan Struktur dan tabel Daftar Informasi). |
| Submit form Permohonan Informasi, Keberatan, modal survei IKM, dan subscribe footer | STG mode baca saja: tombol Kirim/Submit/Daftar tidak boleh ditekan. Yang dites: validasi inline, aturan tombol disabled, opsi dropdown, tampilan terisi. Pesan sukses/gagal, validasi sisi server, nomor registrasi, email konfirmasi, dan proteksi spam/rate-limit tidak teruji. |
| Kebenaran data vs sumber acuan resmi | Plan belum mengisi "Sumber acuan data". Yang dicek: API ↔ UI dan konsistensi antar halaman. Isi dokumen resmi (dasar hukum, biografi, nomor peraturan) perlu diverifikasi admin/PPID desa. |
| Sorting kolom Daftar Informasi | Tidak ada fitur sort pada kolom tabel (header tidak interaktif). |
| Paginasi >1 halaman | Hanya 3 data (limit 5) sehingga paginasi 1 halaman; navigasi halaman 2+ tidak bisa dimunculkan tanpa menambah data. API `page=2` mengembalikan `data: []` dengan benar. |
| Empty state & loading state halaman statis | Data selalu ada di STG; empty state daftar dites lewat pencarian tak berhasil ("Tidak ada informasi publik yang ditemukan." → lolos). Empty state bagan Struktur/IKM tidak bisa dimunculkan tanpa mengubah data. |
| Dark mode | Halaman publik tidak punya dark mode (`.claude/DESIGN.md` §13). |
| Halaman butuh login | Menu PPID publik tidak butuh login; admin CMS `/admin/*` di luar scope dan tidak diakses (tanpa kredensial). |
| Perilaku bagan Struktur "Fullscreen" & fokus node | Tidak ditekan/diuji mendalam; hanya Zoom In/Out, Reset, dan pencarian yang dicoba. |

### Catatan teknis
- Branch lokal `stg` tertinggal dari STG; rujukan file:baris memakai kode lokal dan bertanda "dugaan": `src/app/darmasaba/_com/Footer.tsx:45,60`, `…/ppid/indeks-kepuasan-masyarakat/page.tsx:92,206,379,472`, `…/ppid/permohonan-keberatan-informasi-publik/page.tsx:321`, `…/ppid/daftar-informasi-publik/page.tsx:37-59`, `…/ppid/daftar-informasi-publik/[id]/page.tsx:36,41`, `…/ppid/struktur-ppid/page.tsx:177`.
- Semua halaman PPID memanggil `/api/desa/musik/find-many?page=1&limit=50` (±7 KB, pemutar musik global); tidak dihitung sebagai temuan PPID.
- Header respons HTML halaman PPID: `Cache-Control: s-maxage=31536000` (cache CDN 1 tahun). Data dimuat client-side sehingga konten tidak basi, tetapi perubahan teks statis/SSR bisa tertahan di CDN; perlu dikonfirmasi saat deploy.
- Waktu muat: 1,2–2,5 dtk (hangat); muat pertama dingin Profil 4,7 dtk & Struktur 6,5 dtk di HP. Gambar profil: webp 25 KB (wajar). Tidak ada gambar berukuran berlebihan.
- Warning Recharts IKM muncul di 3 ukuran layar; tidak ada error JS lain di 8 halaman utama.
- Footer "© 2025", `not-found.tsx` default, dan HSTS sudah dilaporkan di laporan menu lain (komponen global); sebagian disebut ulang di sini karena berdampak pada alur PPID.
- Script pengumpul data: salinan di `/tmp/qc-ppid/` (`collect.js`, `txt.js`, `api.js`, `det.js`, `val*.js`, `srch*.js`, `nav.js`, `a11y.js`); screenshot bukti 40+ file berawalan `ppid-` di `qc-screenshots/`.
