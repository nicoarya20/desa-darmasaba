### Pola lintas menu (akar bersama)
- **`deletedAt` terisi pada data aktif** (`isActive: true`) di modul Lingkungan, Kesehatan (kelahiran/kematian), dan Pendidikan. Kemungkinan berasal dari seed/backfill. Ini menyebabkan hasil pencarian dan daftar tidak konsisten.
- **Paginasi/limit default:** halaman memanggil `load()` tanpa limit atau filter (Data Lingkungan halaman 2 kosong; Data per Banjar hanya 10 dari 12 banjar; Distribusi Agama/Umur mencampur beberapa tahun).
- **404:** di Lingkungan berupa soft-404 (HTTP 200 + teks slug); di menu lain halaman default Next.js berbahasa Inggris tanpa navbar. Index menu (`/darmasaba/<menu>`) tidak punya landing page.
- **ID detail tidak valid** → loader tanpa akhir atau halaman kosong; sebagian API membalas 500 alih-alih 404.
- **Global:** `<title>` dan meta description sama di semua halaman; tombol ikon (kembali, search, burger) tanpa `aria-label`; footer "© 2025"; header HSTS tidak dikirim.
- **Kebocoran data pribadi (PII) lewat API publik tanpa login** (prioritas tertinggi): Kesehatan membuka NIK, HP, alamat balita dan data ibu hamil (termasuk status keguguran) serta data kelahiran/kematian/penyakit per orang; PPID membuka nama responden survei serta email/telepon pegawai (termasuk yang nonaktif); Desa membuka PII pegawai. Perlu pembatasan/penyaringan field di sisi API, bukan hanya di UI.
- **Data dummy/tes tampil di halaman publik** di hampir semua menu (mis. "TEST 1" di PPID, data uji dan link mati di Layanan, data duplikat massal di Desa).
- **Angka salah di Ekonomi dan Beranda (Kritis/Tinggi):** Jumlah Pengangguran menampilkan 0 Orang karena hanya mengambil 10 dari 18 data; angka PADesa berbeda jauh dari halaman APBDes 2026 dan rumus Sisa Anggaran salah; Penduduk Miskin 2,165 adalah jumlah semua tahun; total APBDes 2025 di Beranda terhitung ganda sehingga persentase realisasi salah. Pola sama dengan limit/filter default di atas.
- **Link footer "Informasi Publik" dan "Transparansi" 404 di semua halaman** (temuan Beranda, juga muncul di PPID).
- **Kontak darurat dummy/tidak konsisten** (Keamanan: Polres Badung dua nomor berbeda, BPBD sama dengan Damkar); form Laporan Publik kemungkinan 401 karena belum masuk `PUBLIC_POST_PATHS` (tidak bisa diverifikasi tanpa POST).
- **Swagger `/api/docs` terbuka publik** di STG (temuan Desa).
- **WebKit/Safari belum dites** di semua menu: Playwright WebKit crash (Bus error) di macOS 14.2 mesin ini.

Screenshot bukti ada di `qc-screenshots/` dengan prefix nama menu (`lingkungan-`, `kependudukan-`, `pendidikan-`, `musik-`, `ppid-`, `desa-`, `kesehatan-`, `beranda-`, `keamanan-`, `ekonomi-`).

### Tidak bisa dites & alasannya

- **WebKit / Safari:** Playwright WebKit diketahui crash (Bus error) di mesin ini dan Safari MCP tidak dipakai sesuai brief, sehingga layout khusus Safari tidak diverifikasi.
- **Submit form Beasiswa & Peminjaman Buku:** sesuai aturan mode baca saja, tidak di-submit. Respons backend (pesan sukses/gagal, endpoint POST, whitelist auth publik) tidak dites.
- **Jenis Kelamin (Select) & Tanggal Lahir/Tanggal Pinjam (DatePicker):** hanya dicek secara statis (label wajib *), interaksi pemilihan tidak dites.
- **Kebenaran angka terhadap sumber resmi** (jumlah siswa/pengajar/sekolah, data pendidikan penduduk, dana beasiswa): tidak ada dokumen acuan. Yang dicek hanya konsistensi UI ↔ API dan kewajaran data. Konsistensi lintas menu (mis. Kependudukan) ditangani worker lain.
- **Dark mode:** halaman publik tidak punya dark mode (sesuai DESIGN.md §13).
- **Halaman yang butuh login / admin CMS:** di luar scope dan tidak boleh login.
- **Tablet 768px:** dicek otomatis (overflow, gambar, teks) dan lolos. Screenshot visual hanya diambil untuk 375 dan 1440.

### Catatan teknis
- Branch lokal `stg` tertinggal dari STG; rujukan file:baris memakai kode lokal dan bertanda "dugaan": `src/app/darmasaba/_com/Footer.tsx:45,60`, `…/ppid/indeks-kepuasan-masyarakat/page.tsx:92,206,379,472`, `…/ppid/permohonan-keberatan-informasi-publik/page.tsx:321`, `…/ppid/daftar-informasi-publik/page.tsx:37-59`, `…/ppid/daftar-informasi-publik/[id]/page.tsx:36,41`, `…/ppid/struktur-ppid/page.tsx:177`.
- Semua halaman PPID memanggil `/api/desa/musik/find-many?page=1&limit=50` (±7 KB, pemutar musik global); tidak dihitung sebagai temuan PPID.
- Header respons HTML halaman PPID: `Cache-Control: s-maxage=31536000` (cache CDN 1 tahun). Data dimuat client-side sehingga konten tidak basi, tetapi perubahan teks statis/SSR bisa tertahan di CDN; perlu dikonfirmasi saat deploy.
- Waktu muat: 1,2–2,5 dtk (hangat); muat pertama dingin Profil 4,7 dtk & Struktur 6,5 dtk di HP. Gambar profil: webp 25 KB (wajar). Tidak ada gambar berukuran berlebihan.
- Warning Recharts IKM muncul di 3 ukuran layar; tidak ada error JS lain di 8 halaman utama.
- Footer "© 2025", `not-found.tsx` default, dan HSTS sudah dilaporkan di laporan menu lain (komponen global); sebagian disebut ulang di sini karena berdampak pada alur PPID.
- Script pengumpul data: salinan di `/tmp/qc-ppid/` (`collect.js`, `txt.js`, `api.js`, `det.js`, `val*.js`, `srch*.js`, `nav.js`, `a11y.js`); screenshot bukti 40+ file berawalan `ppid-` di `qc-screenshots/`.

### Catatan teknis
- Branch lokal `stg` tertinggal dari STG `0.1.202`; rujukan `file:baris` memakai kode lokal dan bertanda "dugaan". Beberapa perilaku STG (Google Maps, modal validasi layanan) tidak ada di kode lokal.
- Footer "© 2025", HSTS, header global, tooltip burger, dan 404 default sudah/akan dilaporkan di laporan menu lain (komponen global); di sini hanya dicatat bila berdampak pada menu Desa.
- Penghargaan berada di `/darmasaba/penghargaan` (bukan di bawah `/desa`), sesuai href di `src/con/navbar-list-menu.ts`.
- Bukti No. 6 sengaja tidak memuat screenshot detail pegawai agar PII tidak tersimpan di repo; email/telepon di laporan ini dimasker.
- Berkas stray di repo: `src/app/darmasaba/(pages)/desa/layanan/page.txt` dan `page2.txt` (salinan lama halaman, bukan bagian situs; hanya catatan kebersihan).
- Skrip pengumpul data ada di scratchpad worker (`/tmp/qcdesa/*.js`: audit, dump, detail, i1–i5).

### Yang Tidak Bisa Dites & Alasannya

- **WebKit/Safari:** Playwright WebKit crash (Bus error) di mesin ini; tidak diuji (tidak ada waktu untuk jalur alternatif). Layout card di Safari tidak terverifikasi.
- **Submit form pendaftaran kegiatan** (`/jadwal-kegiatan-page/create`) dan subscribe email di footer: tidak ditekan (aturan STAGING baca-saja). Validasi sisi server, pesan error server, dan keterbacaan data yang baru dikirim tidak diuji. Endpoint `POST/PATCH/DELETE` tidak dicoba, sehingga tidak diketahui apakah ada yang tidak terlindungi auth.
- **Halaman admin** (`/admin/...`) di luar scope dan butuh login (tidak ada kredensial).
- **Dark mode:** halaman publik tetap light (sesuai DESIGN.md §13), tidak ada yang diuji.
- **Sumber acuan data eksternal:** plan belum menyediakan; data hanya dibandingkan antara API dan UI serta antarhalaman. Kebenaran nama puskesmas/nomor telepon terhadap dunia nyata tidak diverifikasi.
- **Kontras warna & ukuran gambar menyeluruh:** hanya diuji sampel (gambar mobile ≈ 60–75 KB, desktop terbesar 441 KB); kontras tidak dihitung ulang.

### Yang Tidak Bisa Dites & Alasannya

- **WebKit/Safari:** Playwright WebKit crash (Bus error) di mesin ini; layout beranda di Safari tidak terverifikasi.
- **Submit "Ajukan Responden" dan "Daftar" (berlangganan) di footer:** tidak ditekan (aturan STAGING baca-saja). Validasi sisi server, pesan sukses/gagal, penyimpanan data responden, dan perilaku `POST /api/subscribe` tidak diuji. Tombol "Submit" modal responden hanya dinilai dari kode (`kepuasan/index.tsx`).
- **Statistik cepat (jumlah penduduk/KK/banjar) di beranda:** tidak ada di STG 0.1.202 (hero hanya memuat Jam Operasional, modul, sosial media, dan sapaan Perbekel); karena itu konsistensi angka beranda vs Kependudukan/Ekonomi dibatasi pada APBDes, IKM, SDGs, Layanan, dan Penghargaan/Prestasi.
- **Chatbot dan player musik bawah:** tidak ada chatbot interaktif di beranda (hanya ikon dekoratif di footer, No. 11). `FixedPlayerBar` tidak tampil di beranda karena baru muncul setelah lagu diputar dari halaman Musik, sehingga tidak diuji (di luar scope beranda).
- **Berita/pengumuman baru saat polling:** tidak ada cara membuat berita baru tanpa login admin, sehingga munculnya badge/notifikasi baru setelah polling tidak teramati (hanya interval request 30 detik dan konten popup).
- **Halaman admin dan login:** di luar scope, butuh login (tidak ada kredensial).
- **Dark mode:** halaman publik hanya mode terang (sesuai `DESIGN.md` §13), tidak diuji.
- **Sumber acuan data eksternal:** plan belum menyediakan; data hanya dibandingkan antara API dan UI serta antarhalaman. Kebenaran angka APBDes 2026 terhadap dokumen resmi desa, nama penghargaan, dan keaslian foto tidak diverifikasi.
- **Kontras warna menyeluruh dan pembaca layar sungguhan:** hanya sampel visual; tidak dihitung rasio kontras per elemen dan tidak diuji dengan NVDA/VoiceOver.
- **Link eksternal modul/sosmed:** hanya dicek HTTP status dari sisi server (sosial media 200 semua); isi halaman tujuan dan sertifikat `darmasaba.desa.id` diuji lewat `openssl`/Node, bukan di peramban.

### Catatan Teknis

- Tool: `playwright-cli -s=qc-beranda run-code` (skrip sekali jalan per skenario × 3 viewport), screenshot disimpan di `qc-screenshots/beranda-*.png` (36 file). Session ditutup di akhir (`playwright-cli -s=qc-beranda close`). Skrip bantu ada di `/tmp/qcb` (di luar repo), tidak ada perubahan pada kode atau data.
- Jam diuji dengan `page.clock.install` pada konteks baru dengan `timezoneId` berbeda. Throttling (Slow 4G: 1,6 Mbps/150 ms, CPU 4x) lewat CDP pada konteks baru, sehingga tidak memengaruhi pengujian lain. Penundaan API 4 detik (No. 32) dipakai hanya pada satu skenario (`page.route`) lalu dihapus (`unrouteAll`); pengukuran waktu respons dilakukan ulang setelahnya (semua API 250–1.000 ms).
- Rujukan kode (lokal tertinggal dari STG 0.1.202, bisa sedikit beda): `src/app/darmasaba/_com/Footer.tsx:45,60,134,141`; `src/app/darmasaba/_com/main-page/landing-page/index.tsx:26-77` (jam operasional), `ModuleView.tsx:30-36,117-118`, `ProfileView.tsx:72`; `main-page/layanan/index.tsx:119`; `main-page/kepuasan/index.tsx:50-62`; `main-page/sdgs/index.tsx:63`; `NavbarMainMenu.tsx`, `NavbarSubMenu.tsx`; `ModernNewsNotification.tsx` (tanpa `z-index`). Widget aksesibilitas (No. 27) belum ada di kode lokal.
- Hasil pengamatan keterlambatan: satu kali `page.goto` ke `/darmasaba` kena timeout 30 detik saat pengujian berurutan (tidak bisa direproduksi pada pemuatan berikutnya, waktu muat normal <1 detik); dicatat sebagai anomali.

- **WebKit/Safari:** Playwright WebKit crash (Bus error) di mesin ini; tidak diuji. Layout di Safari tidak terverifikasi.

### Yang Tidak Bisa Dites & Alasannya

- **WebKit/Safari:** Playwright WebKit crash (Bus error) di mesin ini; tidak diuji.
- **Submit "Pesan Sekarang" (UMKM)** dan **"Hubungi Pemilik/Hubungi Sekarang"** (buka `wa.me`): tidak ditekan (aturan baca-saja; submit membuat catatan penjualan dan mengurangi stok). Hanya modal dibuka dan diisi tanpa kirim. Apakah `POST /api/ekonomi/umkm/penjualan/create` publik atau 401, apakah server memvalidasi harga/stok, tidak diketahui (No. 7 dari pembacaan kode).
- **Form lamaran kerja:** tidak ada di STG (hanya WhatsApp "Hubungi Sekarang"); subscribe email footer tidak ditekan.
- **Halaman admin** (`/admin/ekonomi/...`) di luar scope dan butuh login (tidak ada kredensial); dashboard UMKM hanya diperiksa lewat API.
- **Dark mode:** halaman publik tetap light (DESIGN.md §13), tidak diuji.
- **Sumber acuan data eksternal:** plan tidak menyediakan; data hanya dibandingkan API vs UI dan antarhalaman. Kebenaran angka dunia nyata (jumlah penduduk miskin, pengangguran, APBDes) tidak diverifikasi.
- **Kontras warna menyeluruh & ukuran gambar menyeluruh:** hanya sampel.
- **Endpoint POST/PUT/DELETE:** tidak dicoba, sehingga proteksi auth sisi server untuk penulisan tidak terverifikasi.
