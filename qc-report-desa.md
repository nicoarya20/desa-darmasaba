## Menu Desa

- **Target:** https://desa-darmasaba-stg.wibudev.com/ (versi STG `0.1.202`)
- **Tanggal:** 2 November 2026
- **Scope:** menu **Desa** saja (acuan `MIND/PLAN/plan-qc-1-Nov.md` bagian 1–3)
- **Tool:** `playwright-cli -s=qc-desa` (Chromium headless) + GET read-only ke API publik. Mode baca saja: tidak ada form yang di-submit (form "Ajukan Permohonan" hanya diisi untuk uji validasi, tombol Simpan tidak ditekan), tidak ada data yang diubah, tidak login.
- **Ukuran layar:** 375x812 (HP), 768x1024 (tablet), 1440x900 (desktop)

**Yang lolos:**
- Semua 11 halaman daftar + 9 jenis detail mengembalikan HTTP 200, tidak ada scroll horizontal di 375/768/1440 **kecuali** Kegiatan Desa di HP (No. 11).
- Tidak ada console error/warning dan tidak ada request 4xx/5xx pada halaman dengan data valid (404 hanya muncul pada uji ID tidak valid).
- Tidak ada gambar rusak (`naturalWidth = 0`) dan tidak ada `<img>` tanpa atribut `alt` (alt kosong hanya 1 di index Desa, No. 13). Teks `undefined`/`null`/`NaN`/`[object Object]`/`Invalid Date` tidak ditemukan.
- Semua API 200, 250–450 ms (satu outlier: `/potensi/find-many` ±1,1 s); load halaman 1,1–2,8 detik (sampel pertama detail Berita di HP 9,9 detik, tidak terulang).
- Paginasi, pencarian, dan filter berfungsi: Berita (cari "festival" → 3 hasil, "zzzzqq" → "Tidak ada berita ditemukan", tab Budaya, halaman 2), Pengumuman (cari, halaman 26, kategori), Kegiatan (cari "mareresik"), Layanan (cari "usaha"), Event Budaya (halaman 7 = 4 data, 34 total), Video (15 halaman).
- Jumlah kategori pengumuman (0+45+0+0+0+31) = 76 = total API. Jumlah halaman berita/event/layanan sesuai total API.
- Validasi form "Ajukan Permohonan" (Layanan detail) jelas: error per field setelah blur, NIK/KK dibatasi 16 digit angka, tombol Simpan nonaktif sampai valid. Escape menutup modal.
- Menu navbar desktop (hover → 9 submenu) dan hamburger HP (9 submenu Desa, item aktif tersorot) berfungsi; tombol kembali berfungsi; link sosial footer dan oss.go.id 200.
- ID detail tidak valid pada Berita, Video, Potensi, Layanan, Penghargaan, Kegiatan menampilkan pesan Bahasa Indonesia ("Data tidak ditemukan", dst.). Embed YouTube dan embed Google Maps di Profil tampil.
- Tidak ada API key/secret/connection string di HTML halaman (kecuali No. 32 yang dicatat terpisah).

### Tidak bisa dites & alasannya

| Item | Alasan |
|---|---|
| **WebKit/Safari** | Playwright WebKit diketahui crash (Bus error) di mesin ini; sesuai instruksi tidak dicoba ulang dan Safari MCP tidak dipakai. Layout Desa perlu dites manual di Safari (terutama kartu Layanan, Potensi, Penghargaan). |
| Kebenaran data vs sumber acuan resmi | Plan belum mengisi "Sumber acuan data". Yang dicek: kesesuaian API ↔ UI, konsistensi antar halaman dan duplikasi. Kebenaran isi konten (sejarah, visi-misi, kalender Galungan, periode perbekel) perlu dikonfirmasi admin desa. |
| **Submit form Permohonan Layanan** | Mode baca saja. Form hanya diisi untuk validasi; hasil submit, email/WA notifikasi, dan data tersimpan tidak dites. |
| Pelayanan Penduduk Non-Permanent, form permohonan lain di Layanan | Hanya teks informasi; tidak ada form lain yang terbuka tanpa login di scope Desa. |
| Unduhan PDF Telunjuk Sakti | Host `darmasaba.desa.id` bersertifikat TLS tidak valid; isi PDF tidak bisa diverifikasi (temuan No. 2). |
| Subscribe footer ("Daftar") | Tidak ditekan (mode baca saja); kolom email diperiksa hanya dari DOM (tanpa label, No. 25). |
| Dark mode | Halaman publik tidak punya dark mode (`.claude/DESIGN.md` §13). |
| Lightbox/zoom Gallery Foto | Klik foto tidak membuka apa pun (tidak ada fitur); tidak ada halaman detail foto untuk dites. |
| Tes Tab keyboard menyeluruh & pembaca layar | Hanya audit statis nama aksesibel/heading; urutan fokus dan pembaca layar tidak diuji penuh. |
| Zona waktu non-WITA | Mesin uji memakai `Asia/Makassar`; tampilan tanggal/jam untuk pengguna di zona waktu lain tidak diuji. |
| Halaman butuh login | Menu Desa publik tidak butuh login; admin CMS di luar scope. |

### Catatan teknis
- Branch lokal `stg` tertinggal dari STG `0.1.202`; rujukan `file:baris` memakai kode lokal dan bertanda "dugaan". Beberapa perilaku STG (Google Maps, modal validasi layanan) tidak ada di kode lokal.
- Footer "© 2025", HSTS, header global, tooltip burger, dan 404 default sudah/akan dilaporkan di laporan menu lain (komponen global); di sini hanya dicatat bila berdampak pada menu Desa.
- Penghargaan berada di `/darmasaba/penghargaan` (bukan di bawah `/desa`), sesuai href di `src/con/navbar-list-menu.ts`.
- Bukti No. 6 sengaja tidak memuat screenshot detail pegawai agar PII tidak tersimpan di repo; email/telepon di laporan ini dimasker.
- Berkas stray di repo: `src/app/darmasaba/(pages)/desa/layanan/page.txt` dan `page2.txt` (salinan lama halaman, bukan bagian situs; hanya catatan kebersihan).
- Skrip pengumpul data ada di scratchpad worker (`/tmp/qcdesa/*.js`: audit, dump, detail, i1–i5).
