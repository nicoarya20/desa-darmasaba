## Beranda (Landing Page)

- **Target:** https://desa-darmasaba-stg.wibudev.com/darmasaba (versi STG `0.1.202`)
- **Tanggal:** 2 November 2026
- **Scope:** halaman **Beranda** dari atas sampai footer (navbar + menu hover/hamburger, pencarian navbar, hero + sapaan Perbekel, Jam Operasional, modul inovasi, sosial media, APBDes, Penghargaan, Layanan, Potensi, Desa Anti Korupsi, Indeks Kepuasan Masyarakat, SDGs, Prestasi, popup/panel berita (polling 30 detik), widget aksesibilitas, footer + semua link-nya). Acuan `MIND/PLAN/plan-qc-1-Nov.md` bagian 1–3.
- **Tool:** `playwright-cli -s=qc-beranda` (Chromium headless) + GET read-only ke API publik. Mode baca saja: tidak ada form yang di-submit (Ajukan Responden, Daftar footer tidak ditekan), tidak ada data diubah, tidak login.
- **Ukuran layar:** 375x812 (HP), 768x1024 (tablet), 1440x900 (desktop)

**Inti masalah Beranda:**
- Dua link footer ("Informasi Publik", "Transparansi") mengarah ke halaman yang **404** di semua halaman situs.
- **APBDes tahun 2025** menampilkan total yang dihitung ganda (Total Pendapatan Rp 3,35 M padahal induk 4 = Rp 1,5 M), sehingga persentase realisasi salah.
- Pencarian navbar **tidak ada di HP/tablet**, dan di desktop banyak hasilnya yang salah alamat (404, halaman kosong, URL berisi `undefined`).
- Bagian hero: 5 dari 8 modul inovasi tersembunyi di dalam area scroll 280 px yang scrollbar-nya tak terlihat, dan kartu modul tidak bisa dibuka dengan keyboard.

**Yang lolos:**
- Tidak ada scroll horizontal di 375/768/1440 (scrollWidth = lebar viewport); tidak ada gambar rusak (`naturalWidth = 0`) dan semua `<img>` punya `alt`; tidak ada teks `undefined` / `null` / `NaN` / `[object Object]` / lorem ipsum di beranda.
- Semua request beranda 200 (API 240–1.000 ms terisolasi); tidak ada request 4xx/5xx; tidak ada console error. Satu-satunya console warning: Recharts "The width(-1) and height(-1) of chart should be greater than 0" (sama dengan temuan Kesehatan No. 14).
- 67 submenu navbar (10 menu) semuanya terbuka tanpa 404; menu hover desktop, link aktif, dan hamburger HP bekerja (tombol burger membuka dan menutup menu).
- Polling berita tepat 30 detik (`/api/news/latest` pada detik 1, 31, 61, 91); popup "Berita Terbaru" menutup sendiri setelah ±10 detik; panel lonceng berisi 3 berita + 3 pengumuman sesuai API.
- Jam Operasional: Senin–Kamis 07:30–15:30, Jumat 07:30–12:00, Sabtu/Minggu "Libur Akhir Pekan", hari libur nasional dari API `harilibur/cek` (25 tanggal dites) berfungsi dengan zona waktu perangkat WITA.
- Indeks Kepuasan Masyarakat: angka grafik (jenis kelamin, rating, umur, per bulan) cocok 100% dengan API `responden`.
- SDGs: rata-rata 42,13% cocok dengan hitung manual dari 18 nilai; nilai kartu beranda cocok dengan halaman SDGs.
- Total Pendapatan/Belanja APBDes 2026 sama dengan jumlah baris di API.
- 4 ikon sosial hero dan 4 di footer membuka Instagram/TikTok/YouTube/Facebook yang benar (`target=_blank`, `rel=noopener noreferrer` pada footer); URL sosial media semua merespons 200.
- Pencarian: kata kunci tanpa hasil menampilkan "Tidak ada hasil"; `<script>alert(1)</script>` tidak tereksekusi (tidak ada XSS); karakter `%'` tidak error.
- Halaman detail 8 modul inovasi semuanya termuat (200) dengan isi sesuai nama.
- `<html lang="id">`, favicon, meta description beranda, dan viewport ada; seluruh akses lewat HTTPS; tidak ada API key/token di HTML beranda (grep `api_key|secret|token|password|minio|seafile` kosong).
- Kontrol navbar punya fokus ring saat Tab (2 px); 4 ikon sosial hero berfungsi.

### Yang Tidak Bisa Dites & Alasannya

- **WebKit/Safari:** Playwright WebKit crash (Bus error) di mesin ini; layout beranda di Safari tidak terverifikasi.
- **Submit "Ajukan Responden" dan "Daftar" (berlangganan) di footer:** tidak ditekan (aturan STAGING baca-saja). Validasi sisi server, pesan sukses/gagal, penyimpanan data responden, dan perilaku `POST /api/subscribe` tidak diuji. Tombol "Submit" modal responden hanya dinilai dari kode (`kepuasan/index.tsx`).
- **Statistik cepat (jumlah penduduk/KK/banjar) di beranda:** tidak ada di STG 0.1.202 (hero hanya memuat Jam Operasional, modul, sosial media, dan sapaan Perbekel); karena itu konsistensi angka beranda vs Kependudukan/Ekonomi dibatasi pada APBDes, IKM, SDGs, Layanan, dan Penghargaan/Prestasi.
- **Chatbot dan player musik bawah:** tidak ada chatbot interaktif di beranda (hanya ikon dekoratif di footer, No. 11). `FixedPlayerBar` tidak tampil di beranda karena baru muncul setelah lagu diputar dari halaman Musik, sehingga tidak diuji (di luar scope beranda).
- **Berita/pengumuman baru saat polling:** tidak ada cara membuat berita baru tanpa login admin, sehingga munculnya badge/notifikasi baru setelah polling tidak teramati (hanya interval request 30 detik dan konten popup).
- **Halaman admin dan login:** di luar scope, butuh login (tidak ada kredensial).
- **Dark mode:** halaman publik hanya mode terang (sesuai `DESIGN.md` §13), tidak diuji.
- **Sumber acuan data eksternal:** plan belum menyediakan; data hanya dibandingkan antara API dan UI serta antarhalaman. Kebenaran angka APBDes 2026 terhadap dokumen resmi desa, nama penghargaan, dan keaslian foto tidak diverifikasi.
- **Kontras warna menyeluruh dan pembaca layar sungguhan:** hanya sampel visual; tidak dihitung rasio kontras per elemen dan tidak diuji dengan NVDA/VoiceOver.
- **Link eksternal modul/sosmed:** hanya dicek HTTP status dari sisi server (sosial media 200 semua); isi halaman tujuan dan sertifikat `darmasaba.desa.id` diuji lewat `openssl`/Node, bukan di peramban.

### Catatan Teknis

- Tool: `playwright-cli -s=qc-beranda run-code` (skrip sekali jalan per skenario × 3 viewport), screenshot disimpan di `qc-screenshots/beranda-*.png` (36 file). Session ditutup di akhir (`playwright-cli -s=qc-beranda close`). Skrip bantu ada di `/tmp/qcb` (di luar repo), tidak ada perubahan pada kode atau data.
- Jam diuji dengan `page.clock.install` pada konteks baru dengan `timezoneId` berbeda. Throttling (Slow 4G: 1,6 Mbps/150 ms, CPU 4x) lewat CDP pada konteks baru, sehingga tidak memengaruhi pengujian lain. Penundaan API 4 detik (No. 32) dipakai hanya pada satu skenario (`page.route`) lalu dihapus (`unrouteAll`); pengukuran waktu respons dilakukan ulang setelahnya (semua API 250–1.000 ms).
- Rujukan kode (lokal tertinggal dari STG 0.1.202, bisa sedikit beda): `src/app/darmasaba/_com/Footer.tsx:45,60,134,141`; `src/app/darmasaba/_com/main-page/landing-page/index.tsx:26-77` (jam operasional), `ModuleView.tsx:30-36,117-118`, `ProfileView.tsx:72`; `main-page/layanan/index.tsx:119`; `main-page/kepuasan/index.tsx:50-62`; `main-page/sdgs/index.tsx:63`; `NavbarMainMenu.tsx`, `NavbarSubMenu.tsx`; `ModernNewsNotification.tsx` (tanpa `z-index`). Widget aksesibilitas (No. 27) belum ada di kode lokal.
- Hasil pengamatan keterlambatan: satu kali `page.goto` ke `/darmasaba` kena timeout 30 detik saat pengujian berurutan (tidak bisa direproduksi pada pemuatan berikutnya, waktu muat normal <1 detik); dicatat sebagai anomali.
- Waktu respons API terisolasi 250–1.000 ms; satu endpoint (`prestasidesa`) 1.020 ms pada pemanggilan pertama (dingin). Lalu lintas polling: 1 request per 30 detik ±3 KB (`/api/news/latest` mengirim ulang seluruh isi 6 item tiap kali, tanpa ETag/304).
- Bandingkan dengan laporan menu lain bila relevan: Kesehatan No. 11/12 (soft-404 sub-path dan ID detail), No. 25 (limit tanpa batas), serta ketiga temuan global di atas.
