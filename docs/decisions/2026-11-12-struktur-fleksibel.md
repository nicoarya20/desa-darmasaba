# Struktur fleksibel: satu kode untuk Perangkat Desa, PPID, dan BUMDes

Tanggal: 2026-11-12 · Migrasi: `20261112180000_struktur_fleksibel` · Induk: `2026-11-12-struktur-perangkat-desa.md`

## Konteks
Struktur Perangkat Desa sudah memakai kode bersama, tetapi Struktur PPID (dan BUMDes) masih salinan kode lama: semua field pegawai wajib, deskripsi jabatan wajib, atasan jabatan hanya bisa diisi seeder, email unik sehingga pegawai kedua tanpa email gagal disimpan. Desa meminta aturan yang sama untuk ketiga struktur.

## Keputusan
- **Aturan field (ketiga struktur).** Form pegawai: **Nama\*** (sudah termasuk gelar), Foto, Email, Nomor Telepon, **Jabatan\***. Gelar Akademik, Tanggal Masuk, dan Alamat dihapus dari form serta dari detail/list admin. Form jabatan: nama + hierarki wajib; deskripsi, atasan (`parentId`, siklus ditolak `validateParent`), dan `urutan` opsional. String kosong disimpan `null`.
- **Kolom lama tidak dihapus.** `gelarAkademik`/`tanggalMasuk`/`alamat` tetap di DB (rollback aman). Migrasi menggabungkan gelar ke `namaLengkap` dan mengosongkan `gelarAkademik`; seeder PPID memakai aturan yang sama (`gabungGelarKeNama` di `src/lib/struktur-organisasi/`). API masih menerima ketiga field itu secara opsional; form tidak mengirimnya, jadi nilai lama tidak berubah saat PUT.
- **Kode bersama, tabel terpisah.**
  - API: factory `src/app/api/[[...slugs]]/_lib/_struktur-organisasi/` — `createStrukturHandlers({ posisi, pegawai, pegawaiLabel, pegawaiLabelLower, softDelete })` + `createStrukturModule({ prefix, posisiPath, pegawaiPath, tag, logTag }, handlers)`. Delegate Prisma dibaca lazy.
  - `softDelete`: PPID `true` (punya `deletedAt` dan dirujuk tabel lama `StrukturPPID`/`StrukturOrganisasiPPID`; hapus = isi `deletedAt` + nonaktif, foto dibiarkan, semua baca mengabaikan baris terhapus). Perangkat Desa & BUMDes `false` (tanpa `deletedAt`; hapus baris + foto).
  - Hapus jabatan yang masih dipakai pegawai/bawahan ditolak 409. (Opsi `hardDelete` untuk membersihkan rujukan tabel lama `StrukturOrganisasiBumDes` sudah dihapus bersama tabelnya — lihat bagian di bawah.)
  - State: `src/app/admin/(dashboard)/_state/struktur-organisasi/` — `createStrukturState({ logTag, pegawaiLabel, pegawaiLabelLower, api: { posisi, pegawai } })` (node Eden API struktur itu).
  - Admin: halaman bersama di `src/app/admin/(dashboard)/_com/struktur-organisasi/halaman/` (Pegawai list/detail/tambah/edit, Jabatan list/tambah/edit, Bagan, layout tab) dikonfigurasi `StrukturAdminConfig` = `{ state, routes: strukturAdminRoutes(base), text }`. Halaman per struktur hanya pembungkus tipis.
  - Publik: bagan + profil memakai adapter `StrukturSource` per struktur.
- **Kompatibilitas endpoint PPID.** Path lama `/api/ppid/strukturppid/{posisiorganisasi,pegawai}/…` dipertahankan; bentuk respons diselaraskan dengan Perangkat Desa (`{ success, message, data }`, error = status HTTP + `{ success: false, message }`, list pegawai berpaginasi di DB maks 100). Semua konsumen di repo ikut diubah. Endpoint yang tidak dipakai lagi dihapus: `GET|PUT /strukturppid/:id` (tabel lama `StrukturPPID`), `GET posisiorganisasi/find-many`, `GET pegawai/find-many-all`, `DELETE pegawai/non-active/:id`, `PATCH pegawai/active/:id`. Kontrak dikunci `__tests__/api/struktur_ppid_kontrak_route.test.ts`.
- **Kompatibilitas endpoint BUMDes.** Path lama `/api/ekonomi/struktur-organisasi/{posisi-organisasi,pegawai}/…` dipertahankan (`softDelete: false`); bentuk respons diselaraskan dengan Perangkat Desa seperti PPID (sebelumnya campuran `Response` manual dan objek tanpa status HTTP), body pegawai kini hanya `namaLengkap` + `posisiId` wajib (dulu `imageId` wajib di create, `id` wajib di body PUT), body jabatan menerima `deskripsi`/`urutan`/`parentId` opsional. Endpoint yang dihapus karena tak dipakai siapa pun lagi: `GET|PUT /struktur-organisasi/:id` (tabel lama `StrukturBumDes`; satu-satunya pemakai `stateStruktur` admin sudah mati), `GET posisi-organisasi/find-many` (berpaginasi; diganti `find-many-all`). Kontrak dikunci `__tests__/api/struktur_bumdes_kontrak_route.test.ts` (+ daftar rute di `bumdes_kontrak_route.test.ts`).
- **URL admin BUMDes.** Menu `ekonomi.bumdes` (path `…/profil`, basePath `/admin/ekonomi/Struktur-Organisasi-Dan-Sk-Pengurus-BumDes`) tetap. Bar tab: Profil BUMDes · Unit Usaha (tidak berubah) · Pegawai · Jabatan · Bagan (`strukturTabs` bersama). URL lama `posisi-organisasi/…` dan `struktur-organisasi` di-redirect (`legacyJabatanRedirect` bersama, juga dipakai PPID). Publik: chart PrimeReact `OrganizationChart` + `struktur.css` diganti bagan & profil bersama (adapter `struktur-bumdes.source.ts`).
- **Profil publik tanpa Alamat/Tanggal Masuk (ketiga struktur).** `StrukturDetailView` hanya menampilkan email, telepon, dan status. Field itu tidak bisa lagi diedit admin, jadi menampilkan nilai lama yang tak bisa dikoreksi menyesatkan; kolom & data lama di DB dibiarkan (API masih mengirimnya).
- **URL admin PPID.** Menu `ppid.struktur-ppid` (basePath `/admin/ppid/struktur-ppid`) tetap. Tab baru `pegawai`, `jabatan`, `bagan`; URL lama `posisi-organisasi/…` dan `struktur-organisasi` di-redirect ke tab setara.

## Konsekuensi
- Ketiga struktur (Perangkat Desa, PPID, BUMDes) kini memakai factory API, state, halaman admin, dan bagan/profil publik yang sama; tiap struktur hanya punya config (delegate, label, rute, teks) dan adapter sumber publik.
- `primereact` tidak lagi dipakai komponen mana pun; `primereact` + `primeicons` beserta import CSS temanya di `src/app/globals.css` sudah dihapus (branch `chore/remove-primereact`). Satu-satunya warisan tema yang dipertahankan: `font-feature-settings` di `:root` (varian glyph SF Pro).
- Tabel lama `StrukturBumDes` & `StrukturOrganisasiBumDes` dihapus — lihat bagian berikut.

## Tabel usang BUMDes dihapus
Migrasi: `20261112200000_drop_struktur_bumdes_lama`.
- `StrukturOrganisasiBumDes` (tak pernah ditulis/dibaca kode) dan `StrukturBumDes` (tak ada lagi UI/API pengisinya) dihapus dari schema Prisma beserta relasi baliknya di `PosisiOrganisasiBumDes`, `PegawaiBumDes`, dan `FileStorage`. Data pegawai/jabatan BUMDes ada di `PegawaiBumDes`/`PosisiOrganisasiBumDes` dan tidak tersentuh.
- Pencarian publik tipe `strukturOrganisasi` (per-tipe & gabungan) kini membaca pegawai BUMDes aktif pada jabatan aktif (`_lib/search/struktur-bumdes.search.ts`; cocok ke nama, email, telepon, nama jabatan). Item `{ id, name, jabatan }`; tautannya ke profil pegawai `/ekonomi/Struktur-Organisasi-Dan-Sk-Pengurus-BumDes/[id]` (`searchUrl.tsx`).
- Factory struktur tidak lagi punya opsi `hardDelete`; hapus pegawai/jabatan BUMDes memakai `delete` biasa seperti Perangkat Desa.
- **Bila tabel berisi.** Migrasi hanya `DROP TABLE` bila tabel kosong. Bila berisi, DROP dilewati (deploy tidak gagal) dan `RAISE NOTICE` mencetak nama tabel + jumlah baris. Aplikasi tetap jalan karena Prisma tidak lagi memetakan tabel itu; operator memutuskan manual (periksa isi, lalu DROP). Selama `StrukturOrganisasiBumDes` berisi masih ada, FK `ON DELETE RESTRICT`-nya tetap menolak hapus pegawai/jabatan yang dirujuknya.
