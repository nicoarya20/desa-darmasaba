## Menu Kesehatan

- **Target:** https://desa-darmasaba-stg.wibudev.com/ (versi STG `0.1.202`)
- **Tanggal:** 2 November 2026
- **Scope:** menu **Kesehatan** saja (`/darmasaba/kesehatan/...`), acuan `MIND/PLAN/plan-qc-1-Nov.md` bagian 1–3
- **Tool:** `playwright-cli -s=qc-kesehatan` (Chromium headless) + GET read-only ke API publik. Mode baca saja: tidak ada form yang di-submit, tidak ada data yang diubah, tidak login.
- **Ukuran layar:** 375x812 (HP), 768x1024 (tablet), 1440x900 (desktop)

**Yang lolos:**
- Tidak ada scroll horizontal di 375/768/1440 pada semua halaman Kesehatan **kecuali** Data Kesehatan Warga di 375 (No. 14).
- Semua API list/detail valid mengembalikan 200 dalam 240–1.200 ms; halaman termuat 1,5–3,9 detik; gambar konten sudah webp (mobile ≈ 60–75 KB, 1 gambar desktop 441 KB).
- Tidak ada teks `undefined` / `null` / `NaN` / `[object Object]` / `Invalid Date` / lorem ipsum (cek case-sensitive) di semua halaman.
- Semua `<img>` di konten punya `alt`; tidak ada gambar rusak selain No. 13 dan artikel "Test" (No. 10).
- Pencarian dan filter Balita berfungsi dan cocok dengan API (`search=ni` → 22 data, filter Stunting → 10 data, kata kunci `zzzqq%'` → empty state "Tidak ada data balita ditemukan", tanpa error); paginasi meneruskan `search`/`statusStunting` saat ganti halaman (`page=2&limit=10&search=ni`).
- Paginasi daftar Program Kesehatan (11 data → 4 halaman), Penanganan Darurat, Kontak Darurat, Info Wabah, Puskesmas cocok dengan `total` API.
- Jumlah "Total: 26 balita" dan "Total: 16 ibu hamil" cocok dengan API dan kartu Ringkasan (26 balita terdaftar).
- Menu hamburger HP → Kesehatan → 7 submenu berfungsi (uji "Info Wabah/Penyakit" bernavigasi benar); menu hover desktop & link aktif navbar (garis bawah) benar; semua kontrol navbar punya fokus ring saat Tab.
- Tidak ada request 4xx/5xx selain `/img/default.png` (No. 13); tidak ada console error selain itu; seluruh akses lewat HTTPS.
- Tidak ada API key/token di respons API atau HTML yang dicek; ID detail tidak valid pada API mengembalikan 404 JSON `{"success":false,"message":"Data tidak ditemukan"}` (benar di sisi API).

### Yang Tidak Bisa Dites & Alasannya

- **WebKit/Safari:** Playwright WebKit crash (Bus error) di mesin ini; tidak diuji (tidak ada waktu untuk jalur alternatif). Layout card di Safari tidak terverifikasi.
- **Submit form pendaftaran kegiatan** (`/jadwal-kegiatan-page/create`) dan subscribe email di footer: tidak ditekan (aturan STAGING baca-saja). Validasi sisi server, pesan error server, dan keterbacaan data yang baru dikirim tidak diuji. Endpoint `POST/PATCH/DELETE` tidak dicoba, sehingga tidak diketahui apakah ada yang tidak terlindungi auth.
- **Halaman admin** (`/admin/...`) di luar scope dan butuh login (tidak ada kredensial).
- **Dark mode:** halaman publik tetap light (sesuai DESIGN.md §13), tidak ada yang diuji.
- **Sumber acuan data eksternal:** plan belum menyediakan; data hanya dibandingkan antara API dan UI serta antarhalaman. Kebenaran nama puskesmas/nomor telepon terhadap dunia nyata tidak diverifikasi.
- **Kontras warna & ukuran gambar menyeluruh:** hanya diuji sampel (gambar mobile ≈ 60–75 KB, desktop terbesar 441 KB); kontras tidak dihitung ulang.
