## Menu Keamanan

- **Target:** https://desa-darmasaba-stg.wibudev.com/ (versi STG `0.1.202` menurut brief)
- **Tanggal:** 2 November 2026
- **Scope:** menu **Keamanan** saja (`/darmasaba/keamanan/...`), acuan `MIND/PLAN/plan-qc-1-Nov.md` bagian 1–3
- **Tool:** `playwright-cli -s=qc-keamanan` (Chromium headless) + GET read-only ke API publik. Mode baca saja: tidak ada form yang di-submit (termasuk Laporan Publik), tidak ada data yang diubah, tidak login.
- **Ukuran layar:** 375x812 (HP), 768x1024 (tablet), 1440x900 (desktop)

**Yang lolos:**
- Tidak ada scroll horizontal di 375/768/1440 pada semua halaman Keamanan (`scrollWidth == innerWidth`).
- Tidak ada teks `undefined` / `null` / `NaN` / `Invalid Date` / `[object Object]` / lorem ipsum di semua halaman (cek case-sensitive pada teks tampilan).
- Semua `<img>` konten punya atribut `alt`; gambar konten berformat webp kecil (21–41 KB, dua gambar Tips hanya 1 KB); tidak ada console error/warning selain yang tercatat di No. 6.
- Semua API list/detail valid mengembalikan 200 dalam 0,3–1,0 detik; halaman termuat 2,2–4,3 detik (terlama Tips Keamanan di HP, sekali 4,3 detik). Tidak ada request 4xx/5xx selain pada rute ID tidak valid.
- Peta Leaflet CCTV (9 marker) dan 3 peta Google Maps di Semua Polsek termuat benar; marker bisa dibuka (popup kode/status/nama/lokasi) dan tidak ada permintaan izin kamera/mikrofon, tidak ada `<video>`/stream.
- Pencarian berfungsi dan cocok dengan API: Keamanan Lingkungan (`siskamling`), Kontak Darurat (`polisi`, kata tanpa hasil → pesan "Tidak ada kontak darurat yang ditemukan"), Program Lainnya (`maling`), Laporan Publik (`pohon`), Tips (`penipuan`), CCTV (`pasar`); input `zzzqq%'` dan `<script>alert(1)</script>` tidak menimbulkan error maupun eksekusi skrip (tanpa hasil).
- Detail Pencegahan Kriminalitas dengan ID tidak valid menampilkan "Data tidak ditemukan" + tombol "Kembali ke daftar" (benar).
- Menu hamburger HP → Keamanan menampilkan 7 submenu dengan item aktif tersorot; menu desktop dan link aktif benar; semua kontrol navbar punya fokus ring saat Tab; Kontak Darurat dapat dijelajahi dengan Tab.
- Seluruh akses lewat HTTPS; tidak ada API key/token di respons yang dicek; API Laporan Publik tidak membocorkan identitas pelapor (model tidak menyimpan pelapor); respons `find-many` Keamanan tidak memuat NIK/email.

### Yang Tidak Bisa Dites & Alasannya

- **WebKit/Safari:** Playwright WebKit crash (Bus error) di mesin ini; tidak diuji. Layout di Safari tidak terverifikasi.
- **Submit "Tambah Laporan" Laporan Publik** dan subscribe email di footer: tidak ditekan (aturan baca-saja). Karena itu No. 1 (kemungkinan 401 karena belum di whitelist) dan No. 2 (XSS laten) hanya dari tinjauan kode/kebijakan auth, bukan bukti runtime. Validasi sisi server, moderasi, serta endpoint `POST/PUT/DELETE` tidak dicoba, sehingga tidak diketahui apakah ada yang tidak terlindungi auth.
- **Live stream CCTV:** tidak ada stream/iframe/izin kamera di halaman, jadi tidak ada yang dites selain peta dan metadata (No. 9).
- **Halaman admin** (`/admin/...`) di luar scope dan butuh login (tidak ada kredensial).
- **Dark mode:** halaman publik tetap light (DESIGN.md §13), tidak diuji.
- **Sumber acuan data eksternal:** plan belum menyediakan; data hanya dibandingkan antara API dan UI serta antarhalaman. Kebenaran nomor telepon/alamat polsek terhadap dunia nyata tidak diverifikasi (hanya ketidakkonsistenan internal).
- **Kontras warna & ukuran gambar menyeluruh:** hanya sampel (kontras 7 elemen dihitung; gambar 5 berkas diukur).
