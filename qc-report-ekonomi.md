## Menu Ekonomi

- **Target:** https://desa-darmasaba-stg.wibudev.com/ (versi STG `0.1.202`)
- **Tanggal:** 2 November 2026
- **Scope:** menu **Ekonomi** saja (`/darmasaba/ekonomi/...`), acuan `MIND/PLAN/plan-qc-1-Nov.md` bagian 1–3. Sebagai pembanding lintas-halaman, `/darmasaba/apbdes` (di luar menu) ikut dibuka.
- **Tool:** `playwright-cli -s=qc-ekonomi` (Chromium headless) + GET read-only ke API publik. Mode baca saja: tidak ada form/pesanan yang di-submit, tidak ada data yang diubah, tidak login.

**Yang lolos:**
- Tidak ada scroll horizontal pada dokumen (`scrollWidth = clientWidth`) di 375/768/1440 pada semua halaman Ekonomi; overflow hanya di dalam kontainer yang di-clip (No. 15, 16).
- Semua 11 rute menu terbuka (HTTP 200); semua API list/detail valid mengembalikan 200 dalam 310–950 ms; halaman termuat 1,0–3,3 detik.
- Tidak ada `undefined`, `null`, `NaN`, `[object Object]` di teks halaman. Semua `<img>` punya atribut `alt`.
- Pencarian Lowongan (`search=kasir`) dan pencarian UMKM (`ayam`) mengembalikan hasil yang benar; paginasi Lowongan (6/halaman → 2 halaman) dan Kesejahteraan benar.
- Format Rupiah di UMKM/Produk ("Rp 80.000 / ekor") dan format tanggal Indonesia ("23 Juli 2026") benar.
- Fallback `no-image.jpg` bekerja untuk Kesejahteraan; WA link UMKM dibentuk benar (`0823…` → `wa.me/62823…`).

### Yang Tidak Bisa Dites & Alasannya

- **WebKit/Safari:** Playwright WebKit crash (Bus error) di mesin ini; tidak diuji.
- **Submit "Pesan Sekarang" (UMKM)** dan **"Hubungi Pemilik/Hubungi Sekarang"** (buka `wa.me`): tidak ditekan (aturan baca-saja; submit membuat catatan penjualan dan mengurangi stok). Hanya modal dibuka dan diisi tanpa kirim. Apakah `POST /api/ekonomi/umkm/penjualan/create` publik atau 401, apakah server memvalidasi harga/stok, tidak diketahui (No. 7 dari pembacaan kode).
- **Form lamaran kerja:** tidak ada di STG (hanya WhatsApp "Hubungi Sekarang"); subscribe email footer tidak ditekan.
- **Halaman admin** (`/admin/ekonomi/...`) di luar scope dan butuh login (tidak ada kredensial); dashboard UMKM hanya diperiksa lewat API.
- **Dark mode:** halaman publik tetap light (DESIGN.md §13), tidak diuji.
- **Sumber acuan data eksternal:** plan tidak menyediakan; data hanya dibandingkan API vs UI dan antarhalaman. Kebenaran angka dunia nyata (jumlah penduduk miskin, pengangguran, APBDes) tidak diverifikasi.
- **Kontras warna menyeluruh & ukuran gambar menyeluruh:** hanya sampel.
- **Endpoint POST/PUT/DELETE:** tidak dicoba, sehingga proteksi auth sisi server untuk penulisan tidak terverifikasi.
